# The Vault

The **Vault** is the raw editor for bodies: every Document's text, as plain markdown with its
fields on top, in a tree of Folders. It is to bodies what a [Base](bases.md) is to fields — the
place for bulk edits, moves and fixes.

Writing has its own places — the Journal, Notes, Research, Manuscript and Thoughts. The Vault is
always there beside them, and any body with no place of its own opens here.

## Getting there

- **Go to Vault** in the palette (Ctrl+K).
- **Write in the Vault** from a [Peek](peek.md).
- It opens on **Touched last**: the twelve bodies you changed most recently, each with a link to
  its own page.

## The sidebar

- **New** — make a Document of any body-first type (a Day opens the Journal on today instead).
  **Document types…** at the foot opens [Bases](bases.md).
- **Files** — the Folder tree.
  - Right-click a Folder: **New …** of each type, **New folder**, **Rename**, **Move to…**,
    **Delete (empty only)**.
  - Right-click a Document: **Rename**, **Move to…**, **Delete**.
  - Drag Documents and Folders to move them.
  - The lock button: set up, unlock or lock the Private folder.
- **Search** — find words in titles, aliases and bodies, with the line that matched.
- **Tags** — every tag, and what carries it.

## The editor

- **Read / Edit** (✎, ⌘E or Ctrl+E) — a Document can open to read; tap the text or ✎ to write.
- **Fields and Tags** above the body (on a phone, behind the sliders button).
- **Raw text** (`</>`) — the fields as frontmatter and the body together, as one plain text. Edit
  and **Apply**. Guarded fields stay read-only here.
- **Links panel** — links, backlinks, unlinked mentions and names. See [Links](links.md).
- `[[` starts a link; `#word` adds a tag; drop or paste an image to attach it.
- The **⋯** menu: open the type's Base, add or drop a Role, **Delete**.

## The Private folder

`Private` at the root, shown only while unlocked. See "The Private folder" in [Documents](documents.md).

## On a phone

- Folder tabs in the Phone dock: **Thoughts**, **Quotes**, **Writings**. Each remembers the
  Document you last had open in it.
- The tree, search and tags are in the ☰ drawer.
- A Document opens to read, so the keyboard does not cover it uninvited.

## Tips

- Use the Vault for the plain-text jobs: fixing a heading in many notes, moving a folder,
  reading frontmatter.
- For everyday writing, use the Module made for it — it knows what the Document is for.
