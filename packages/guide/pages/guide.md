# About the Guide

The **Guide** is Lifeline's own manual: what exists and how to use it, read inside the app. It
follows what you open — one page for each Module, each Surface, and each thing you meet
everywhere.

## Opening it

- **The Guide button** at the foot of the Rail (desk) — opens the page for where you are: the
  Module you are in, the Surface, Bases, Screens, Settings, the Vault. Anywhere else, its home page,
  [Getting around](index.md).
- **?** in the phone's header — the same, on a phone.
- **The palette** (Ctrl+K) — type "guide" and a name for its Guide entries, one per page:
  "Guide · Money", "Guide · Capture"…

## Reading it

- Each Module's page has a part for each thing it holds, listing what you can do and where:
  the page itself, the Capture sheet, the palette, a Card you can place.
- **Capture** — what **+** and Ctrl+K offer from that Module.
- **Ask Claude** — what Claude can do there, and the tool it uses.
- **Related** — links to the pages next door.
- Start from [Getting around](index.md) for the list of every page.

## Claude reads it too

Through the Lifeline connector, Claude can read the same pages — so you can ask it how something
works. See [Claude](connector.md).

## Tips

- The Guide ships with the app: when Lifeline changes, its Guide changes with it.
- It only explains. Nothing you do in the Guide changes your Documents.
