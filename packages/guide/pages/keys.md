# Keys

Give any Command a key of your own, so it runs on the desk without opening the palette. Open them
in **Settings → Keys**.

## Binding a key

- **Bind a key** — pick a Command, then press the key that runs it. A key needs ⌘ (Ctrl off a
  Mac), with ⌥/Alt or ⇧/Shift if you like.
- Keys Lifeline already uses (⌘K, ⌘E, ⌘., ⌘1–9, ⌘↵) and the browser's own (copy, paste, new
  tab…) are refused. A key you already gave another Command shows as taken, with the Command
  it runs.
- A Command that needs details and has no dialog to ask for them (**Add event from a template**)
  cannot have a key: it says so when you pick it. Type it in the palette with `!` instead; see
  [Capture](capture.md).
- The pencil changes a binding; **×** removes it, with Undo.
- A binding whose Command no longer exists (its App was removed) is marked **Dead**: clear it.

## Pressing a key

- The Command runs at once when it needs nothing more; one that asks for something (a mood, a
  title) opens its dialog; one that goes somewhere goes there. A [Macro](macros.md) asks its
  up-front form, if it has one, and runs.
- Keys are yours across every Workspace and every desk device. They do nothing on a phone.
- The palette shows a Command's key beside it.
