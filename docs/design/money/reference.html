Lifeline Money, the design

    
This is the working design of the Money part of Paul's app, Lifeline. It comes in two looks, Pro and Play, each dark or light. Both hold exactly the same things.

    
    
      
  • Change the look and the theme in the module's own Settings (the gear).
    • 
      
  • Use it for real: import a statement, give transactions a category, spend from a pocket, change a budget, read the reports, add a receipt.
    • 
      
  • It is all made-up data. Nothing is saved, and reloading starts over.
    • 
      
  • Give feedback is still there if something feels wrong.
