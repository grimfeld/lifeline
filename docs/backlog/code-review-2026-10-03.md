## Core — packages/core

- [x] **CR-01 · bug · high — syncNow can run two cycles at once.** `packages/core/src/data/sync.ts:278-292`. `syncing = true` is set only after `await boundAccount()`, so concurrent triggers (focus/online/interval/debounce) both pass the guard and push the same new record. The second `create` hits `validation_not_unique`, which is reported as ForeignRecordError and tells the user to erase unpushed data. *Fix:* set `syncing = true` before the first await and reset it on the early returns. *Fixed in PR #69.*
- [x] **CR-02 · bug · high — Renaming a folder undoes moves and drops link rewrites.** `packages/core/src/documents/ops.ts:68-78, 98-102`. `rewriteReferrers` writes `{...other, body}` from a stale snapshot, so it reverts sibling moves and loses earlier rewrites. *Fix:* rewrite each referrer once after all the moves, applying every (old, new) pair, or re-read each row before writing it. *Fixed in PR #69.*
- [x] **CR-03 · perf · high — A locked Private folder makes every link-index consumer rebuild the whole index.** `packages/core/src/private.ts:271-273`, `documents/links.ts:279-291`. Each `usePrivateLockedRefs` returns new Sets, which breaks the single-slot cache, so every consumer runs a full `buildLinkIndex` on every change. *Fix:* use `sharedLiveQuery` for the locked refs. *Fixed in PR #69.*
- [x] **CR-04 · bug · medium — Switching Workspace leaves Document lists showing the old Workspace.** `packages/core/src/documents/store.ts:76,84`, `attachments.ts:127`. The scope is the in-memory `currentId` and the live queries have no Workspace dependency. *Fix:* re-subscribe the shared query when `setCurrentWorkspace` runs, pass `wsId` in the deps, and use async queriers (see screens.ts:68). *Fixed in PR #69.*
- [x] **CR-05 · bug · medium — Paginated pull can skip records for good.** `packages/core/src/data/sync.ts:213-239`. Offset paging over `sort: updated` shifts rows when one is updated during the pull. *Fix:* keyset pagination (`updated > lastSeen`, with an id tie-break). *Fixed in PR #69.*
- [ ] **CR-06 · bug · medium — Renames don't update locked Private notes.** `packages/core/src/attachments.ts:263`, `documents/ops.ts:46-53,65`. Bodies are read through the gated `allDocuments()`, so links inside locked Private notes break. *Fix:* refuse while locked, or rewrite referrers from an ungated read. *Open — needs a decision:* PR #69 refuses renames and moves while Private is locked (ADR 0038); the MCP server always runs locked, so MCP renames and moves would fail for Accounts with Private notes. The alternative is rewriting referrers from an ungated read.
- [x] **CR-07 · perf · medium — Every no-body Document is rewritten when its push syncs back.** `packages/core/src/data/sync.ts:63,87`, `data/reconcile.ts:29`. `toLocal` keeps `body: ""` where the local row has no body, so `sameRecord` fails and the write triggers an index rebuild. *Fix:* drop `""` bodies for `body: "none"` types, or treat a missing body and `""` as equal. *Fixed in PR #69.*
- [x] **CR-08 · perf · medium — One record that keeps failing to push freezes the pull cursor.** `packages/core/src/data/sync.ts:227-231`. Every cycle re-downloads a growing window. *Fix:* hold back only that record, or stop holding after N failures. *Fixed in PR #69.*
- [x] **CR-09 · perf · low — Placement queries do full scans although a `date` index exists.** `packages/core/src/contracts/surface.ts:49-51, 364-375`. *Fix:* `where("date").between(...)` and filter out deleted rows. *Done (partial by design), PR #69:* the busy-hours read uses the date index; the surfaces still need every Placement, but now share one read.
- [x] **CR-10 · bug · low — A block ending at midnight counts as already over.** `packages/core/src/contracts/surface.ts:58-62`. The comparison `"00:00" > now` is wrong for midnight ends. *Fix:* reuse the end logic in push.ts (end ≤ start means midnight). *Fixed in PR #69.*

## PocketBase + MCP

- [x] **CR-11 · security · medium — The fetch proxy is an open SSRF and buffers whole responses.** `pocketbase/pb_hooks/fetch.pb.js:15-34`. Any account can reach loopback, `.internal` and link-local hosts and forward arbitrary headers, and the 2 MB cap is checked only after the full body is read. *Fix:* block private targets (including after redirects) and check Content-Length or stream with a cap. *Done:* `pb_hooks/fetch_guard.js` refuses loopback, private, link-local and reserved IPs, non-canonical numeric hosts, IPv6 literals, single-label names and private suffixes (`.internal`, `.local`, …). The redirect, DNS and buffering gaps move to CR-72.
- [ ] **CR-72 · security · low — The fetch proxy still follows redirects and resolves names unchecked, and buffers whole bodies.** `pocketbase/pb_hooks/fetch.pb.js`. `$http.send` follows redirects and the JSVM can't resolve DNS, so a public host that redirects to, or resolves to, a private address still gets through, and the 2 MB cap is still checked after the full read. *Fix:* a Go-side PocketBase extension (a custom dialer that checks the resolved IP, a redirect check, and a `LimitReader`), or an egress firewall on the Fly machine.
- [x] **CR-12 · bug · medium — create_document can write into Private and then report failure.** `mcp/src/handlers.ts:301-310`. The Private check runs after the save. *Fix:* resolve the folder (`defaultFolder`) and run the check before `createDocument`. *Fixed in PR #67.*
- [x] **CR-13 · bug · medium — update_document applies the move or rename before validating fields.** `mcp/src/handlers.ts:319-341`. An invalid field leaves a partial write. *Fix:* validate everything first, then apply. *Fixed in PR #67.*
- [ ] **CR-14 · bug · medium — Writes reported as "will be retried" live only in worker memory.** `mcp/src/worker.ts:482`, `devices.ts:145-150,193-199`. A worker crash or a SIGTERM while PocketBase is unreachable loses the queued writes. *Fix:* persist the outbox on flush failure, or report the write as failed. *Partial, PR #67:* the agent now gets `unconfirmed: true` and an honest warning, lost writes are logged, and the shutdown flush is capped at 20 s. Still open: a durable outbox, which needs a volume or another store.
- [ ] **CR-15 · perf · medium — Each tool call runs a full sync, and a cold start pulls the whole Account.** `mcp/src/worker.ts:459-477`, `devices.ts:93,186`, `fly.toml`. *Fix:* raise FRESH_MS for reads, pull only the collections a tool touches, and persist a per-Account snapshot or cursor. *Partial, PR #67:* reads reuse a pull for 15 s. Still open: pulling only the collections a tool needs, and a per-Account cursor.
- [x] **CR-16 · bug · low — Refresh-token rotation is not atomic.** `mcp/src/oauth.ts:182-197`. Concurrent refreshes race, and a stolen token goes undetected. *Fix:* make the update conditional on the old `refresh_hash`, or allow a short grace window for the previous hash. *Fixed in PR #67.*
- [x] **CR-17 · perf · low — No index matches the sync pull query.** `pb_migrations/1757100000_accounts.js:225`, `1755100000_lifeline_init.js:172`, `1756400000_documents.js:157`. *Fix:* add an `(owner, updated)` index on every synced collection. *Fixed in PR #67.*
- [x] **CR-18 · security · low — The workspaces rules drop the `@request.auth.id != ""` guard.** `pb_migrations/1757400000_workspaces.js:22,40-43`. *Fix:* add a migration that hardens the list, view, update and delete rules. *Done:* `1757800000_workspaces_rules_require_auth.js`.
- [x] **CR-19 · bug · low — Two down() migrations hard-delete synced Documents.** `pb_migrations/1757300000_mood_app.js:91`, `1757600000_library_authors.js:135`. Devices keep ghost rows. *Fix:* tombstone instead (`deleted = 1` and bump `updatedAt`). *Fixed in PR #67.*
- [x] **CR-20 · bug · low — The Mood migration discards moods on daily notes whose title is not a date.** `pb_migrations/1757300000_mood_app.js:50-54`. *Fix:* check `isDate` before removing the field, or derive the date from `createdAt`. *Fixed in PR #67.*
- [x] **CR-21 · perf · low — The in-memory OAuth maps are never swept.** `mcp/src/oauth.ts:94-99,200-216`, `server.ts:357-368`. The `verified` cache and the `attempts` map grow without bound. *Fix:* sweep in `verifyAccessToken` (throttled) and prune `attempts`. *Fixed in PR #67.*
